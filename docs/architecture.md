# Архитектура инфраструктуры проекта

## Общая логика

Инфраструктура разделена на независимые сервисные роли:

- PKI / Certificate Authority
- VPN Gateway
- Monitoring Stack
- Backup Storage

Каждый компонент развёрнут на отдельной ВМ для изоляции рисков.

## Роли компонентов

### CA (PKI / Certificate Authority)

- Хранение Root-ключа
- Подпись сертификатов
- Отзыв сертификатов
- Не доступен извне

### VPN

- Точка входа
- Маршрутизация клиентов
- TLS-аутентификация

### Monitoring

- Сбор метрик
- Алерты
- Наблюдаемость инфраструктуры

### Backup

- Резервные копии конфигураций
- Архивирование PKI / VPN / Monitoring

## Принципы проектирования

- Изоляция ролей
- Минимально открытые порты
- TLS-аутентификация
- Автоматизация bootstrap
- Повторяемость развёртывания
